# ClipVault v0.1.5 手动验收指引（约 5 分钟，真实桌面路径）

> 目的：补齐 v0.1.5 发布前仅剩的两块门禁证据——①三场景真实粘贴 ②真实来源图片捕获。
> 本机已装 0.1.5 构建（10-26 §4 物理核验通过），**无需安装**，直接做以下四步即可。
> 做完把每步 PASS/FAIL 告诉我（有截图更好，扔进本目录也行），我负责打包投 GPT 终审。

## 前置
- ClipVault 正在运行（托盘有图标；没有就双击打开 app）。
- 呼出热键 = **Alt+V**（默认）；呼出后打字过滤、Enter 粘贴。

## ① 记事本粘贴
1. 打开记事本，随便点一下正文区。
2. 在任意地方复制一句话（例如先在记事本输入 `CV-手动验证-记事本-20261028`，Ctrl+A、Ctrl+C）。
3. Alt+V 呼出面板 → 打字输入 `CV-手动` 过滤 → Enter 粘贴。
4. ✅ PASS = 记事本光标处出现这句话，落点正确。

## ② 浏览器输入框粘贴
1. 浏览器开任意带输入框的页面（或本目录 `vm-share\test-input.html` 双击打开）。
2. 点一下输入框 → 复制一句新话（`CV-手动验证-浏览器-20261028`）→ Alt+V → 过滤 → Enter。
3. ✅ PASS = 输入框里出现这句话。
4. ⚠️ 多标签浏览器注意：粘贴落在**呼出面板时正聚焦的那个标签页**（已知边界，正常现象）。

## ③ 原生多控件粘贴（资源管理器地址栏）
1. 打开资源管理器，Alt+D（或点地址栏）聚焦地址栏。
2. 先复制一个真实路径（例如 `C:\Windows`）。
3. Alt+V → 过滤 → Enter → 地址栏跳转到该目录。
4. ✅ PASS = 正确跳转，没有粘到别的窗口。

## ④ 真实来源图片捕获
1. 浏览器随便打开一张图（或截图工具截个屏）。
2. 右键图片 →「复制图片」（或截图）。
3. Alt+V 呼出面板 → 列表里应出现这张图（缩略图可见）。
4. ✅ PASS = 面板出现该图片条目（不必粘贴，出现即算捕获成功）。
