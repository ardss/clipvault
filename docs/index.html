先在网页里试试 Live demo

这就是真实的 ClipVault 面板，跑在你的浏览器里。可以搜索、切换分类、置顶、删除、看统计——数据保存在浏览器的 localStorage，清除站点数据时才会重置。

实际使用中，这一步由 Ctrl+C 完成，不用点任何按钮。

复制密码，它不记住 Privacy

它防什么

  • 密码管理器复制的密码，直接跳过——Bitwarden / 1Password / KeePass 会给这类复制打敏感标记，我们认这个标记
  • 过滤词自己加——比如 token、api-key 开头的内容，命中就不记录
  • 不联网——没有账号，没有云同步，没有遥测

它不防什么

  • 除上面两条之外，所有内容明文存在本机，不加密。它不是保险箱。
  • 介意明文存储的话，别把敏感内容交给它。

已知问题 Known issues

这些是我们知道的毛病，装之前先告诉你。

  • 呼出面板的瞬间会短暂打断打字（面板要接管键盘焦点才能搜索，同类工具都有这个问题）
  • 热键默认 Alt+V，可在设置里改；跟部分 IDE、输入法可能冲突
  • 粘贴靠一个常驻的小进程按键完成，个别杀软可能提示（属正常行为）
  • 搜索不支持拼音和模糊匹配
  • 除密码管理器外，其他敏感内容是明文存储——别把它当保险箱

数据在哪

所有数据都在下面这个目录里。备份 = 复制整个文件夹；彻底清除 = 删掉它。

%APPDATA%\com.clipvault.app\
  • clips.db — 历史记录（SQLite，明文）
  • images\ — 图片条目的 PNG 文件
  • settings.json — 历史上限 / 面板高度 / 开机自启
  • js-errors.log — 界面报错记录（排查问题时发这个）
