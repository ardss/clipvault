快捷键 Shortcuts

按键作用
Alt + V呼出 / 隐藏面板（贴着鼠标弹出）
打字搜索（搜的是内容，不只是标题）
↑ / ↓在条目间移动
Enter粘贴选中项到之前的窗口
Del删除选中项
Esc清空搜索 → 关闭面板
鼠标悬停长文本看全文，图片看大图（可划选复制）

数据在哪 Data

所有数据都在下面这个目录里。备份 = 复制整个文件夹；彻底清除 = 删掉它。

%APPDATA%\com.clipvault.app\
  • clips.db — 历史记录（SQLite，明文）
  • images\ — 图片条目的 PNG 文件
  • settings.json — 历史上限 / 面板高度 / 开机自启
  • js-errors.log — 界面报错记录（排查问题时发这个）

已知问题 Known issues

  • 呼出面板的瞬间会短暂打断打字（面板要接管键盘焦点才能搜索，行业共性难题）
  • 热键固定 Alt+V，暂不可改；与部分 IDE / 输入法可能冲突
  • 粘贴由常驻注入器子进程按键完成，个别杀软可能提示（属正常行为）
  • 搜索不支持拼音和模糊匹配
  • 密码管理器复制的密码已自动跳过；但其他敏感内容仍是明文存储，请勿把它当保险箱

隐私边界 Privacy

  • 没有任何联网功能——数据只在你硬盘上
  • 密码管理器（Bitwarden / 1Password / KeePass）标记的敏感复制不会入库
  • 除此之外的复制内容一律明文存储——它不是保险箱
