# ClipVault 0.2.0 验收清单

候选凭据（不可变）：安装包 `src-tauri/target/release/bundle/nsis/ClipVault_0.2.0_x64-setup.exe`，SHA256 见装机收据；commit SHA 见交付报告。
验收原则（DELIVERY-CONTRACT.md）：每条自己动手操作一遍；任何一条不符 → 报告，状态降级 FAILED。

## A. 边缘三态托盘（P0）

| # | 验什么 | 怎么验 |
|---|---|---|
| A1 | 隐藏态可发现 | 鼠标移到屏幕**左边缘**停约 0.2s，面板从左侧滑出（spring 动效）；左缘有一条细的可发现提示线 |
| A2 | 鼠标离开自动收起 | 面板展开后把鼠标移开（不搜索、不拖拽），约 1s 后面板收回 |
| A3 | 固定态 | 点面板标题栏的 📌 图标 → 状态切换为固定，鼠标离开不再收起；再点一次解除 |
| A4 | 热区开关与配置可持久化 | 设置里关闭"边缘唤出"后重启应用，左缘热区失效；重新开启恢复 |
| A5 | 搜索期间不收起 | 展开面板后在搜索框输入，鼠标移开面板 —— 面板保持展开 |
| A6 | 拖拽期间不收起 | 拖动一张卡片到另一张上方停留，面板不会中途收回 |

## B. 卡片合并 / 堆叠 / 空间分组（P1）

| # | 验什么 | 怎么验 |
|---|---|---|
| B1 | 驻留合并 | 按住卡片 A 拖到卡片 B 上，目标卡片出现高亮/进度指示，停约 0.6s 松手 → 两项合并为一个组卡片（显示计数与堆叠缩略图） |
| B2 | 组展开/收起 | 点组卡片 → 展开子项列表；再点收起 |
| B3 | 拖出拆分 | 展开组后把子项拖出（或点"拖出"）→ 子项回到独立卡片；组剩 1 项时自动解散 |
| B4 | 整体拆组 | 组展开后点"拆组" → 所有子项还原为独立卡片 |
| B5 | 非破坏性 | 合并/拆组后逐条点开子卡片，内容完整无丢失；重启应用后分组关系仍在（SQLite 持久化，非内存态） |
| B6 | 撤销 | 合并后出现 toast，点"撤销"恢复合并前状态 |
| B7 | 重排 | 拖卡片到列表其他位置松手（未落在卡片上）→ 列表顺序改变并持久化 |

## C. 原生 OLE 拖出（P1）

| # | 验什么 | 怎么验 |
|---|---|---|
| C1 | 文本拖进记事本 | 按住一张文本卡片**向外拖**（拖离面板）→ 出现拖拽幽灵，松手到记事本 → 文本落在记事本光标处 |
| C2 | 链接/富文本拖出 | 同上，拖到浏览器地址栏或聊天输入框 |
| C3 | 拖进资源管理器 | 文件类卡片拖到资源管理器 → 落地为文件（文件类支持时；文本类不落地为文件属正常） |
| C4 | 不用假拖拽 | 拖出过程中目标应用（记事本）出现真实系统拖拽光标（复制/移动样式），说明是 OLE DoDragDrop 而非页面内动画 |

## D. 视觉 / 主题 / 动效

| # | 验什么 | 怎么验 |
|---|---|---|
| D1 | 深浅两套玻璃主题 | 切换主题按钮，深浅色下面板均为玻璃质感（半透明+模糊），无样式破碎 |
| D2 | 动效统一 | 展开/收起、卡片悬浮、合并指示都是同一种弹性动效；系统开启"减弱动态效果"时动效退化为直接切换 |
| D3 | 字体四档仍有效 | 设置里滑字体档位（100/110/125/150%），全局缩放生效 |

## E. 多语言与 0.1 功能回归

| # | 验什么 | 怎么验 |
|---|---|---|
| E1 | 7 语言完整 | 语言下拉切 zh/en/ja/ko/es/fr/de，新功能文案（固定/合并/拖出等）每种语言都有翻译，无英文占位混入 |
| E2 | 敏感词过滤开关 | 设置里关闭敏感过滤 → 复制含关键词文本仍被采集；开启 → 被拦截 |
| E3 | 暂停采集 | 托盘菜单"暂停采集"→ 复制不入库；自动恢复时间到 → 恢复采集 |
| E4 | 清空确认弹窗 | 点清空 → 弹确认框，取消不清数据，确认才清 |
| E5 | 快捷键 Alt+V | 全局唤出/隐藏面板 |
| E6 | 旧数据无损 | 升级前记一条已有剪贴板内容；升级后该条还在、可粘贴、置顶标记保留 |
| E7 | 用户数据目录未被动过 | `%APPDATA%\com.clipvault.app` 数据库与图片目录完好（装机收据中有核验记录） |
